# 템플릿

Piko View 화면은 **틀 + 기능 묶음 + 템플릿**으로 정해집니다. 템플릿 파일 하나가 그 회사의 View 를 정합니다.

| 칸 | 뜻 |
|---|---|
| `name`, `title` | 템플릿 이름(파일 이름과 같게)과 화면에 보일 이름 |
| `brand` | 왼쪽 위 이름(기본 `Piko`) |
| `modules` | 켤 기능 묶음. 아직 없는 묶음은 메뉴에서 저절로 빠집니다 |
| `nav` | 왼쪽 메뉴 묶음과 순서. 항목은 `{ "module": "schedules" }`(그 묶음의 기본 메뉴) 또는 `{ "to": "/주소", "label": "이름", "icon": "아이콘" }` |
| `home` | 첫 화면. `stats`(위 숫자 카드)와 `panels`(아래 목록 칸)에 묶음이 주는 카드 이름을 적습니다 |
| `labels` | 부르는 말 바꾸기(예: `"lead": "상담"`) |

기능 묶음(지금 있는 것): `schedules`(일정) · `problems`(문제 해결) · `kb`(지식 베이스) · `docs`(문서).
준비 중: `projects`(프로젝트 · 태스크) · `crm`(고객 · 영업 건) · `comms`(채팅) · `workflows`(자동화).

회사 전용 기능은 공개 템플릿에 넣지 않고, 그 회사의 비공개 묶음 · 비공개 템플릿으로 둡니다. Piko Work 에이전트에게 "우리 회사에 맞게 템플릿 만들어 줘"라고 해서 만들 수도 있습니다.
