# 환불 및 교환 정책

## 하드웨어
- 구매 후 **7일 이내 미개봉** 제품은 전액 환불한다.
- 개봉 후 제품 불량은 **14일 이내 동일 제품으로 교환**한다. 단순 변심에 의한 개봉 제품은 환불하지 않는다.

## 소프트웨어 (클라우드 구독)
- 월 단위 구독은 이미 시작된 달의 요금을 환불하지 않는다.
- 해지 신청 시 다음 달부터 과금이 중지된다.

## 절차
1. 고객이 고객지원 메일로 환불/교환을 요청한다.
2. 고객지원팀이 구매 이력과 제품 상태를 확인한다.
3. 환불 금액이 100만 원을 넘으면 재무팀 확인 후 처리한다.
