# 견적 처리 절차

## 1. 견적 요청 접수
- 고객 요청은 메일, 전화, 홈페이지 문의로 들어온다.
- 담당 영업사원이 영업관리 시스템에 요청을 등록한다.

## 2. 고객 정보 확인
- 기존 고객이면 계약 요약 문서에서 결제 조건과 특별 할인율을 확인한다.
- 신규 고객이면 사업자등록증을 받아 신용 등급을 확인한다.

## 3. 가격 산정
- 반드시 **최신 연도 제품가격표**를 기준으로 한다.
- 수량 할인은 가격표 기준을 따른다.
- 할인율이 **10%를 넘으면 영업팀장 승인**이 필요하다. 15%를 넘으면 본부장 승인까지 받는다.

## 4. 견적서 발송
- 견적서 유효기간은 발행일로부터 30일이다.
- 견적서는 영업관리 시스템에서 PDF로 발행해 메일로 보낸다.

## 5. 기록
- 발송 후 고객 반응과 다음 연락 일정을 시스템에 기록한다.
