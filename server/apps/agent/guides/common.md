## 공통 규칙
- 이 데이터는 화면과 같다. 로그인한 모든 사람이 함께 보고 고치는 공유 데이터다.
- 무엇을 만들거나 고치면 API 토큰 주인이 한 일로 기록된다. 요청받지 않은 변경은 하지 않는다.
- **삭제 도구는 없다.** 지우는 일은 사람이 화면에서 한다. 지워야 할 것 같으면 사람에게 알린다.
- ID는 추측하지 않는다. 목록 도구(`*_list`)나 상세 도구(`*_get`)로 확인한 ID만 쓴다.
- 날짜는 `YYYY-MM-DD`, 시각은 `YYYY-MM-DDTHH:MM`이고 모두 서버 시간대 기준이다.
- 고치기(`*_update`)는 바꿀 항목만 준다. 목록 형태 값(모르는 부분 등)은 통째로 바뀌므로
  먼저 상세 도구로 현재 값을 받아 고친 뒤 전체를 준다.
- 사람 이름이 필요하면 `user_list`로 등록된 사용자를 확인한다.
- 도구가 `오류:`로 시작하는 문장을 돌려주면 그 안내대로 인자를 고쳐 다시 시도한다.
- 작업이 끝나면 무엇을 만들고 무엇을 바꿨는지 ID와 함께 짧게 보고한다.
